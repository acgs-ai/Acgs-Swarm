# Roadmap

This roadmap separates stable runtime hardening from research exploration.

## Stable core priorities
- improve onboarding docs and examples for governed execution and mesh settlement
- Continue API stability for the documented core surface (`AgentDNA`, `ConstitutionalMesh`, `SwarmExecutor`, `TaskDAG`)
- Expand regression coverage around signed-vote settlement and replay/recovery paths

## Advanced runtime priorities
- Improve deployment/operator guidance for remote vote transport (`[transport]`)
- Strengthen examples for receipt verification and settlement evidence workflows
- Continue integration quality for LangGraph and Bittensor optional modules

## Research / experimental priorities
- Iterate on `latent_dna`, `swarm_ode`, and `merkle_crdt` modules
- Maintain `manifold.py` as baseline control while evaluating spectral-sphere direction
- Improve reproducibility assets for benchmark/evaluation scripts and paper claims

## Documentation priorities
- Keep beginner docs separate from deep research drafts
- Keep evidence-linked claims only (tests/scripts/source-backed)
- Expand FAQ and troubleshooting from real contributor questions

## Out-of-scope positioning
This roadmap does **not** imply:
- compliance certification,
- regulator approval,
- universal production readiness across research modules.
