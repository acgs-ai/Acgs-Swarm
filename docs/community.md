# Community and contribution pathways

This project serves multiple contributor groups.

## 1) Developers integrating governed runtime features
Start with:
- [`docs/quickstart.md`](quickstart.md)
- [`docs/concepts.md`](concepts.md)
- [`docs/architecture.md`](architecture.md)

Then use:
- [`README.md`](../README.md) maturity tiers
- [`CONTRIBUTING.md`](../CONTRIBUTING.md)

## 2) Agent-framework maintainers
Focus on:
- stable API boundaries in [`README.md`](../README.md)
- advanced adapters in [`docs/langgraph_runtime.md`](langgraph_runtime.md)
- migration notes in [`MIGRATION.md`](../MIGRATION.md)

## 3) Governance and audit contributors
Focus on:
- settlement + receipts in [`docs/security-model.md`](security-model.md)
- verification scripts in `scripts/verify_governance_receipts.py`
- public replication materials in [`docs/public-replication.md`](public-replication.md)

## 4) Researchers
Use the clearly marked research docs:
- [`docs/maci_dp_protocol.md`](maci_dp_protocol.md) (draft)
- [`paper/README.md`](../paper/README.md)
- `docs/internal/*` internal/research notes

## Ways to contribute
- Fix or improve docs and examples
- Add tests for governance/runtime behavior
- Improve optional integration adapters
- Propose roadmap items with concrete implementation paths

## Communication channels
- Issues: <https://github.com/dislovelhl/Acgs-Swarm/issues>
- Discussions: <https://github.com/dislovelhl/Acgs-Swarm/discussions>
- Security: follow [`SECURITY.md`](../SECURITY.md)
